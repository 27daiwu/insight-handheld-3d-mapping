LooperRobotics Insight 9: Quick Start & Developer Guide (v1.2.1)

Overview

This guide covers the network configuration and startup procedures for the LooperRobotics Insight 9 camera.
  • Operating System: Ubuntu 22.04 (Recommended) Ubuntu 24.04，Windows 11，MacOS Tahoe
  • Middleware: ROS 2 (Humble/Foxy/Rolling)
  • DDS: Cyclone DDS (Recommended)

Introduction of ROS Topics

ROS2 must be installed on the host computer. After connecting the Insight 9 via USB cable, wait for the internal system to boot (approximately 20 seconds). At this point, you should be able to directly access the ROS2 message list published by the Insight 9 on the host computer.

Frequently Asked Questions (FAQ)

What should I do if ROS2 cannot receive messages from Insight 9?

  • Troubleshoot Network Connection: Insight 9 automatically configures the IP address of the virtual network interface on the host side. Please do not manually modify these settings during operation.

  • ROS2 Discovery Mechanism Deadlock: If the underlying discovery mechanism hangs, you may need to restart the ROS2 daemon or service.

  • DDS Issues: Try switching your RMW implementation to Cyclone DDS and attempt to connect again.
